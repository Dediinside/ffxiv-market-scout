# FFXIV Market Scout 0.1.2

Настольное Python-приложение с тёмным русским интерфейсом. Ищет товары для продажи из рецептов ремесленников и ресурсов сборщиков доступного вам уровня. Сравнивает реальные продажи, конкуренцию и денежный результат партии. Работает отдельно от Leve Planner.

## Запуск

Нужен **Python 3.10+ с Tkinter**. В обычной установке Python для Windows Tkinter включён; сторонние библиотеки и API-ключи не нужны.

1. Распакуйте архив в папку, доступную для записи.
2. Дважды нажмите **start.bat**, либо выполните `python run.py` из папки приложения.
3. На вкладке **«Профессии»** включите нужные профессии и впишите реальные уровни. По умолчанию указан Lv 1; каждый из 11 профилей сохраняется независимо.
4. Выберите **мир продажи** и **мир/DC закупки материалов**. Спрос всего DC не подменяет спрос мира, на котором ваш ретейнер продаёт товары.
5. Выберите **источник и профессию перед анализом**, задайте объём партии и расходы, затем нажмите **«Анализировать рынок»**. Бюджет можно оставить пустым; 0 означает нулевой доступный бюджет.
6. Выберите строку для подробного расчёта. Двойной щелчок по товару, кнопка «Открыть товар в Universalis» и ссылки на ингредиенты открывают страницы товаров в браузере.

Оффлайн-проверка: **start_demo.bat** или `python run.py --demo`. Все цены и продажи в DEMO искусственные и явно помечены. Профессии и каталог остаются настоящими. DEMO использует ту же папку настроек; если хотите отдельные настройки, передайте `--settings путь/к/файлу.json`.

В Linux нужен системный пакет `python3-tk`. На macOS нужен Python с работающим Tk. Проверка: `python -m tkinter`.

## Обновления программы

При обычном запуске в фоне проверяется последний стабильный релиз публичного GitHub-репозитория. Токен не нужен. Внизу окна отображается результат и кнопка **«Открыть релизы ↗»**. Проверку можно повторить вручную. При отсутствии сети или лимите GitHub программа продолжает работать; ошибка проверки не означает, что установлена последняя версия. В DEMO автоматическая проверка отключена.

Обновление устанавливается вручную: скачайте ZIP нового релиза, закройте программу и распакуйте его вместо прежних файлов. Профессии и личные замеры сохраняются отдельно в `%LOCALAPPDATA%/FFXIVMarketScout/settings.json`. Проверка версии не обновляет рыночные цены и игровой каталог.

## Спрос обязателен

Высокая цена сама по себе не делает товар рекомендацией. По умолчанию вариант проходит три условия:

- минимум **1 проданная единица в день** в среднем за 7 дней;
- минимум **3 зарегистрированные сделки за 7 дней**;
- последняя продажа не старше **72 часов**.

Эти пороги видны на основном экране и сохраняются. Товары без истории, с одной дорогой сделкой или давно затихшими продажами скрыты. Галочка **«Показать малоликвидные для сравнения»** разрешает диагностический просмотр; такие строки отмечены отдельным статусом. После изменения порогов повторите анализ, чтобы вернуть ранее исключённые товары.

Стандартный фильтр минимальной прибыли 0 скрывает убытки и неизвестный результат. Очистите его для разбора затрат или сравнения. Нажатия на заголовки сортируют числовые столбцы; приоритет позволяет выбрать прибыль, спрос, себестоимость или ближайшее окно сбора.

Показатели «Шт./день» и «Покупок/день» различаются: продажа одного стака из 99 штук означает одну сделку, а не 99 покупателей. История относится к выбранному миру и качеству HQ/NQ. На экране показываются зарегистрированные сделки Universalis, а не гарантированно полный игровой рынок.

Сначала приложение просматривает четырёхдневные агрегаты Universalis для ограниченной выборки товаров. Затем подробно загружает предложения и отдельную семидневную историю для лучших кандидатов. По умолчанию лимиты — **600 товаров / 30 подробных кандидатов**. Первичная выборка распределена между включёнными профессиями и группами уровней; подробная — между профессиями и источниками с сортировкой по спросу внутри каждой группы. Так популярные shards не вытесняют все рецепты из расчёта. На экране видны доступное количество, охват и ограничения; это поиск внутри рассмотренной выборки. Лимиты можно увеличить, лишние профессии отключить. Поиск по названию, источник и профессия перед новым анализом сужают сам каталог. Источник и профессия сохраняются. После их изменения нажмите «Анализировать рынок» для нового поиска; до этого таблица фильтрует старые результаты.

Под статусом показано **«Показано N из M рассчитанных вариантов»**. Если строк нет, нижняя панель объясняет дальнейшие действия: повторить анализ с новым отбором, очистить минимальную прибыль или нажать «Сбросить фильтры». Пустая таблица сама по себе не означает отсутствие выгодных товаров на всём рынке.

История ограничена 1 800 записями на товар. При достижении лимита спрос подписан как **нижняя граница**. Для окончательной закупки приложение запрашивает все предложения API без искусственного лимита в 100 стаков. Mannequin listings исключаются.

## Цена, себестоимость и расходы

Цена продажи — осторожная оценка: минимум медианы цен сделок и самого дешёвого текущего предложения минус 1 gil, с нижним пределом 1 gil. При отсутствии активных предложений используется история; при отсутствии истории текущая цена остаётся сравнением с низкой уверенностью и не проходит обязательный отсев спроса.

Для крафта учитываются **все восемь слотов ингредиентов**, включая shards/crystals/clusters, и выход рецепта:

```text
число крафтов = ceil(желаемая партия / выход рецепта)
фактическая партия = число крафтов × выход рецепта
нужные ингредиенты = количества рецепта × число крафтов
выручка = фактическая партия × оценка цены − налог продажи
денежная прибыль = выручка − полные денежные затраты
```

Ингредиенты покупаются **целыми стаками**. Точный алгоритм выбирает сочетание предложений с минимальной суммой для покрытия потребности. Лишние материалы остаются у вас; их будущая продажа не прибавляется к прибыли. Налог покупки округляется вниз на каждый стак. Налог продажи задаётся вручную, округление вверх даёт осторожную оценку. По умолчанию оба налога 5%; задайте реальные ставки вашего сценария.

HQ-кандидат появляется лишь после подтверждения «Могу HQ» для соответствующего ремесленника. Расчёт предполагает гарантированный HQ из NQ-материалов; вероятность качества и неудачи не моделируются. Книги и специалист разрешаются отдельными сохранёнными галочками. Уровень фильтруется строго; дополнительные требования к экипировке и доступу перечислены в деталях.

На вкладке **«Расходы и настройки»** можно:

- задать еду, зелья/cordial, ремонт, дорогу и прочие затраты **в gil на всю партию**;
- задать дополнительные затраты на один крафт;
- добавить расходник по **ID товара, количеству, качеству и способу производства**: его цена и необходимый стак рассчитываются через рынок автоматически.

Нулевой ручной расход означает **не используем/не учитываем**. Программа не угадывает вашу еду, длительность крафта, число cordial и ротацию. Введите используемые расходники; не дублируйте один расход одновременно ручной суммой и строкой рыночной закупки. Неизвестная цена ингредиента/расходника оставляет себестоимость и прибыль «—». Детали различают отсутствие предложений, недостаточное количество и ошибку API.

Каждая строка — независимая партия и отдельная проверка бюджета. Совместный портфель производства и повторное использование одного закупленного стака между строками не рассчитываются. Свои материалы, рекурсивный крафт промежуточных компонентов, NPC-магазины и стоимость времени в gil в этой версии не оценены.

## Сборщики и интервалы появления

Поддержаны **Miner, Botanist и Fisher**. Ресурсы сбора рекомендуются в NQ; HQ-добыча не предполагается.

Для обычных, timed и ephemeral узлов сохранены место, ограничения и реальные окна из игровых таблиц. В деталях показаны **время Эорзеи, ближайшее окно по местному времени компьютера и ожидание**. Час ET = 175 реальных секунд, сутки ET = 70 реальных минут. Переход через полночь учитывается. Неизвестные условия не подменяются постоянной доступностью. Погода, intuition и цепочки mooching для рыбалки не прогнозируются.

Для timed-ресурсов можно указать личный **урожай за одно окно**; приложение покажет минимальное необходимое число окон для партии. Урожай — ваш замер, а не обещание каталога. Окно появления не означает, что узел бесконечно восстанавливается в течение этого окна.

Ожидание и время окна в открытом интерфейсе обновляются каждые 30 секунд без сетевых запросов. Цены обновляются новым анализом рынка.

При неизвестной скорости сборщик сразу получает оценку спроса и денежного результата партии, а **gil/час остаётся «—»**. Для обычного MIN/BOT можно задать общую скорость. Под таблицей можно сохранить личный замер конкретного товара: за сколько минут собрали сколько единиц, общий расход приманок и урожай за окно. Замер хранится по товару — применяйте его к тому же месту, экипировке и способу добычи.

Для timed-узлов непрерывный gil/час не выводится. Для ephemeral разрешён только активный gil/час внутри окна при личном замере и известном урожае; ожидание не включено. Для обычного сбора показатель тоже относится к активному сбору, не ко времени продажи или всему маршруту.

Для удочки **стоимость приманок на одну целевую рыбу нужно задать**, учитывая промахи и побочные уловы, либо получить из личного замера. Без неё прибыль остаётся неизвестной. Ноль допустим только как явное допущение. Spearfishing отделён от удочки и не требует наживки. Цена собственного запаса приманок/расходников и расход scrips требуют личной оценки.

## Настройки, кэш и обновление

В Windows настройки находятся в `%LOCALAPPDATA%/FFXIVMarketScout/settings.json`. Кэш — рядом в `cache/`. На других системах используется пользовательская папка `.local/share/FFXIVMarketScout`. Обновление распакованной программы сохраняет настройки. Профессии, расходы, рынки, пороги спроса и личные замеры сохраняются автоматически после ввода, отдельной кнопкой и при закрытии окна. Повреждённый файл сохраняется рядом как `.broken-*`, после чего применяются значения по умолчанию.

Кэш: агрегаты 15 минут; предложения и история 10 минут. «Свежие цены» обходит свежий локальный кэш. При сбое API доступен кэш не старше 48 часов **с предупреждением**. Время получения ответа и время рыночного обновления учитываются отдельно. Для сетевых ошибок/429/5xx — максимум три попытки; Retry-After ограничен 15 секундами. Работа идёт в фоновом потоке; отмена останавливает следующие запросы, текущий запрос может ждать таймаута.

В комплекте — **13 029 предметов, 9 580 обычных продаваемых рецептов и 2 749 источников сбора**. Среди источников 225 timed и 98 ephemeral. Снимок 12 октября 2026 из последней опубликованной версии английских таблиц **7.56h1, 17 сентября 2026**, commit `d71de329cc6ed30c6fb16b9108cdf7d29c653302`. Каталог закреплён на одной версии всех таблиц. Это данные сообщества, а не официальный API Square Enix.

Обновление каталога:

```text
python run.py --refresh
```

Загружаются 16 таблиц из одного commit, проверяются ссылки, количества, уровни и расписания. При ошибке прежний каталог сохраняется. Таблица уровней сборщика нормализуется через GatheringItemLevelConvertTable; сырой ID не используется как Lv. Длительность rare-pop расписаний декодируется по игровому формату, включая специальное значение 160; неизвестная новая схема отклоняется. Expert/квестовые рецепты исключены. Миры/DC в этой версии берутся из встроенного списка глобальных регионов.

## Консоль и проверка

```text
python run.py --cli --demo --profession Carpenter:50 --profession Miner:90 --craft-hq
python run.py --cli --profession Miner:20 --sale-world Odin --purchase-scope Light --scan-limit 100 --detail-limit 10
python run.py --cli --profession Carpenter:20 --catalog-search "Maple Lumber"
python run.py --cli --source craft --job Carpenter
python -m unittest discover -s tests -v
```

CLI выводит JSON; параметры CLI не перезаписывают сохранённые настройки. Для вывода UTF-8 в старом терминале Windows можно установить `PYTHONIOENCODING=utf-8`.

Тесты покрывают расходы, HQ/NQ, yield, целые стаки, спрос и ликвидность, уровни и доступ, ET-окна, кэш/API, сохранение настроек, фильтры, ссылки и настоящее окно Tkinter. Подробности сборки — в [VALIDATION.md](VALIDATION.md), структура — в [ARCHITECTURE.md](ARCHITECTURE.md).

Источники: [Universalis API](https://docs.universalis.app/), [FFXIV datamining](https://github.com/xivapi/ffxiv-datamining), [декодирование узлов Teamcraft](https://github.com/ffxiv-teamcraft/ffxiv-teamcraft/blob/staging/apps/data-extraction/src/extractors/nodes.extractor.ts), [время Эорзеи Teamcraft](https://github.com/ffxiv-teamcraft/ffxiv-teamcraft/blob/master/apps/client/src/app/core/eorzea/eorzean-time.service.ts). Игровые названия и данные принадлежат Square Enix; приложение не выполняет действия в клиенте игры.
