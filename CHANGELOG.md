# Изменения

## 0.1.2 — 12 октября 2026

- Проверка стабильных релизов публичного GitHub при запуске, без токена и блокировки интерфейса.
- Статус обновлений, ручная повторная проверка и ссылка на скачивание релиза.
- Обработка отсутствия сети, лимита API и некорректного ответа; DEMO не обращается к GitHub автоматически.
- 87 тестов, включая сравнение версий и проверку отзывчивости интерфейса.

## 0.1.1 — 12 октября 2026

- Исправлен пустой результат Carpenter при включённых сборщиках: источник и профессия теперь ограничивают каталог до запросов рынка, а подробная выборка распределяется по профессиям и источникам.
- Источник и профессия сохраняются; изменение отбора показывает подсказку о повторном анализе.
- Добавлены счётчик видимых результатов, объяснение пустой таблицы и сброс фильтров.
- Добавлены регрессионные проверки: 78 тестов прошли. На Shiva / Light с Carpenter Lv 50 получены 37 вариантов с подтверждённым спросом, 18 с неотрицательной расчётной прибылью при проверке.

## 0.1 — 12 октября 2026

Первый выпуск настольного FFXIV Market Scout.

- Рекомендации крафта и сбора по доступным профессиям и уровням.
- Спрос по сделкам за 7 дней: отсеивание товаров без покупателей, пороги продаж и давности.
- Universalis: отдельный мир продажи и мир/DC закупки, HQ/NQ, кэш и обработка ошибок.
- Расчёт ингредиентов, кристаллов, целых стаков, налогов и заданных расходников.
- Timed/ephemeral узлы: время Эорзеи, ближайшие окна, личные замеры урожая и скорости.
- Сохранение всех 11 профилей, тёмный русский интерфейс, фильтры, сортировка, ссылки и CSV.
- Встроенный каталог, оффлайн-DEMO, консольный запуск и 74 теста.

Для запуска нужен Python 3.10+ с Tkinter. Это отдельное приложение; оно не управляет игровым клиентом.
